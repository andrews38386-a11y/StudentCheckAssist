# Build APK without Android Studio

1. Create a GitHub account at https://github.com/ if you do not already have one.
2. Create a new empty repository, for example `student-check-assist`.
3. Upload ALL files and folders from this project into the repository root.
4. Open the repository's **Actions** tab.
5. Select **Build Student Check Assist APK**.
6. Click **Run workflow** (or push to the `main` branch to trigger it automatically).
7. Wait for the green check to appear.
8. Open the completed workflow run and download the artifact named **Student-Check-Assist-APK**.
9. Extract the downloaded artifact and install `app-debug.apk` on the Android phone.

No Android Studio is required on Windows for this cloud build.
